# Documentation archive

This directory is reserved for historical direction/planning checkpoints that remain useful context but are no longer live project instruction.

Current transitional historical documents still live one level up:

- `../0.2-direction-review.md`
- `../0.2b-critical-course-correction.md`
- `../roadmap-readiness-audit.md`

They should be moved here only during a deliberate documentation cleanup after their live guidance has been fully absorbed into `ROADMAP.md` and `docs/research-state.md`.

## Archive rule

Archiving a document means:

- its historical reasoning remains valuable,
- it must not be mistaken for current execution guidance,
- its claims are not automatically invalidated,
- current direction is determined by `ROADMAP.md` + `docs/research-state.md` + current evidence.

Do not delete historical checkpoints merely because the project changed direction.
