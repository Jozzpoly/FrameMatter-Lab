## Evidence record convention

A useful record states:

- question / hypothesis,
- exact bounded setup,
- PASS / FAIL / unresolved status,
- important measurements,
- what the result actually establishes,
- explicit non-claims / scope limits,
- relevant commit / CI / artifact provenance when useful.

Do not rewrite old evidence because terminology or preferred architecture later changes. Preserve the record and update `research-state.md` or add a newer evidence record.
